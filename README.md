# MotoRent

Rent a bike. Start earning.

## Overview

MotoRent is a production-quality web platform for delivery riders looking to work with rented motorcycles. The platform connects:

- **Delivery riders** - people looking to work but don't own a motorcycle
- **Motorcycle owners/fleets** - offering bikes for delivery work
- **Maintenance providers** - keeping bikes in working condition  
- **Delivery companies** - offering job opportunities

## Features

- Motorcycle marketplace with advanced filtering
- Rental calculator and earnings simulation
- Rider onboarding and profile management
- Job matching and recommendations
- Maintenance provider directory
- Rider dashboard with rental tracking
- Earnings analytics

## Development

You'll need Node.js installed. We recommend using [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd imageready-studio
npm install
npm run dev
```

The dev server will start at `http://localhost:5173`.

### Build

```sh
npm run build
```

### Preview

```sh
npm run preview
```

### Linting

```sh
npm run lint
```

### Formatting

```sh
npm run format
```

## Tech Stack

- **Framework**: TanStack Start (React + TypeScript)
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui (built on Radix UI)
- **Data**: TanStack React Query
- **Routing**: TanStack Router
- **Runtime**: Bun / Node.js
- **Icons**: Lucide React
