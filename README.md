# Rider Hub

MotoRent — Lovable Product Build Prompt ## 1. Product Vision Build a production-quality web platform called **MotoRent** for people who want to work as delivery riders but **do not own a motorcycle**. This is **not a tourism motorcycle-rental website**. The core business journey is: **Rent a motorcycle → Rider onboarding → Find delivery jobs → Maintain the motorcycle → Track earnings** MotoRent should become an ecosystem for delivery riders, motorcycle owners/fleets, maintenance providers, and delivery-job opportunities. The product should feel like a serious Egyptian startup/product, not a generic rental template. --- # 2. Core Problem A potential delivery rider may say: > "I want a motorcycle to work with, but I don't have one." MotoRent should make the entire journey simple: 1. Search for a motorcycle suitable for delivery work. 2. Filter by area, working hours, budget, motorcycle type, and fuel type. 3. Compare available motorcycles. 4. View motorcycle details and rental terms. 5. Apply/request the motorcycle. 6. Complete rider onboarding. 7. Discover suitable delivery jobs. 8. Track rental, work, and earnings. 9. Find nearby maintenance/service providers. 10. Build a long-term rider profile. The platform should optimize for **earning potential**, not tourism. --- # 3. Brand ## Name **MotoRent** ## Suggested tagline **Rent a bike. Start earning.** Alternative supporting message: **Your motorcycle for work. Your next job. One platform.** The brand should communicate: - Mobility - Work - Reliability - Earning - Speed - Accessibility - Trust - Professional delivery operations Avoid a luxury/tourism aesthetic. --- # 4. Target Users Design the product around four primary user types. ## 4.1 Rider A person who wants to work in delivery but doesn't own a motorcycle. Examples: - Delivery beginner - Existing rider whose motorcycle is unavailable - Rider looking for a better/cheaper motorcycle - Student doing part-time delivery - Full-time delivery worker ## 4.2 Motorcycle Owner / Fleet Partner Someone who owns: - One motorcycle - Multiple motorcycles - Delivery-focused motorcycle fleet They can list motorcycles for work rental. ## 4.3 Maintenance Provider Motorcycle mechanics/service centers that can provide: - Oil change - Tires - Brakes - Battery - Electrical repair - Engine service - General maintenance ## 4.4 Employer / Delivery Company Companies that need delivery riders. Examples: - Restaurants - Dark kitchens - E-commerce companies - Pharmacies - Grocery delivery - Logistics companies - Local businesses --- # 5. Primary UX The homepage must immediately answer: > **"I need a motorcycle to work with. What can I rent?"** Do NOT make the homepage feel like a traditional vehicle rental marketplace. The primary CTA should be: **Find a motorcycle** Secondary CTA: **I want to offer my motorcycle** Third CTA: **Find delivery jobs** --- # 6. Homepage Create a modern, highly polished landing page. ## Hero Section Headline: **Rent a motorcycle. Start earning.** Supporting text: **Find a work-ready motorcycle, connect with delivery opportunities, and manage your rider journey from one platform.** Main search card: ### "Find a motorcycle for work" Fields: - Area - Rental duration - Working hours - Daily/weekly budget - Motorcycle type - Fuel type CTA: **Find motorcycles** Add a secondary visual CTA: **Browse available bikes** --- # 7. Motorcycle Search Experience Create a marketplace-style search page. URL concept: `/motorcycles` Layout: - Desktop: filters sidebar + results grid - Mobile: sticky filter button + cards - Clean responsive behavior ## Filters ### Location Examples: - Tanta - Cairo - Giza - Alexandria - Mansoura - Zagazig - 6th of October - Nasr City - New Cairo ### Budget Example: - Under 120 EGP/day - 120–180 EGP/day - 180–250 EGP/day - 250+ EGP/day Allow custom min/max. ### Motorcycle Type - Standard - Scooter - Delivery Bike - Electric Motorcycle - Sport/commuter ### Fuel - Petrol - Electric ### Rental Period - Daily - Weekly - Monthly ### Working Hours - Part-time - Full-time - Flexible ### Requirements - Helmet included - Delivery box included - Maintenance included - Insurance/coverage included - Registration verified --- # 8. Motorcycle Cards Create premium but practical marketplace cards. Example: ## Boxer 150 **120 EGP / Day** Badge: **Delivery Ready** Information: - Petrol - 150cc - Manual - 35–40 km/L - Helmet available - Delivery box available Location: **Tanta** Availability: **Available now** CTA: **View motorcycle** Secondary: **Compare** --- Second example: ## Scooter **180 EGP / Day** - Petrol - Automatic - City optimized - Delivery ready CTA: **View motorcycle** --- Third example: ## Electric Motorcycle **220 EGP / Day** - Electric - Low running cost - Urban delivery optimized - Charging support CTA: **View motorcycle** Use realistic sample data. Do not use fake-looking placeholder lorem ipsum. --- # 9. Motorcycle Details Page Create a complete marketplace detail page. Sections: ## Gallery Large motorcycle image. Use multiple gallery images: - Front - Side - Rear - Dashboard - Storage/delivery box - Tires/brakes if relevant ## Main Information Display: - Model - Brand - Engine/Power - Fuel type - Transmission - Estimated consumption - Rental price - Deposit - Availability - Location - Delivery suitability ## "Why this bike is good for delivery" Show practical metrics: - Estimated daily operating cost - Estimated fuel/electricity cost - Comfortable working hours - Storage capacity - Delivery box compatibility - Maintenance status ## Rental Calculator Allow user to select: - Number of days - Working hours/day Calculate: **Estimated rental cost** Also show: **Estimated operating cost** And: **Estimated total working cost** Do not claim guaranteed income. --- # 10. Earnings Simulation This is a major differentiator. Create an optional calculator: ### "Can this motorcycle work for me?" Inputs: - Rental cost/day - Working hours/day - Estimated daily delivery income - Fuel/electricity cost - Maintenance reserve Output: - Estimated daily revenue - Estimated daily operating cost - Estimated daily rental cost - Estimated daily net - Estimated weekly net - Estimated monthly net Clearly label this as: **Estimate — actual earnings vary by platform, demand, working hours, location, and rider performance.** Use neutral wording and avoid guaranteed-income claims. --- # 11. Rider Onboarding Create a multi-step onboarding flow. ## Step 1 — Basic Profile - Full name - Phone - Area - Preferred working area ## Step 2 — Riding Profile - Experience - Motorcycle experience - Preferred motorcycle type - Petrol/Electric preference - Full-time / Part-time ## Step 3 — Work Preferences - Delivery category - Preferred working hours - Desired daily income range - Preferred locations ## Step 4 — Verification Status Show a professional verification checklist. Examples: - Phone verified - Profile completed - Required documents pending/verified - Rider profile approved Do not require real government IDs or sensitive credentials for this prototype. Use simulated verification states. --- # 12. Job Opportunities Create a dedicated page: `/jobs` Headline: **Find delivery work that fits your motorcycle** Job cards should include: ## Example Job **Delivery Rider** Company: **Local Food Delivery** Location: **Tanta** Work type: **Full-time** Shift: **6 PM – 12 AM** Estimated earnings: **350–500 EGP/day** Requirements: - Motorcycle - Smartphone - Delivery experience preferred CTA: **View opportunity** --- # 13. Smart Matching Create a matching concept between: **Rider profile + Motorcycle + Delivery opportunity** Example: > **92% Match** Why: - Same working area - Motorcycle type accepted - Preferred working hours match - Experience requirement satisfied - Budget compatible Create a clean match score UI. Do not present matching as AI magic. Use understandable matching factors. --- # 14. Maintenance Marketplace Create: `/maintenance` Headline: **Keep your work bike running.** Categories: - Oil Change - Tires - Brakes - Battery - Engine - Electrical - Inspection - General Service Maintenance provider cards: - Provider name - Distance - Rating - Services - Starting price - Opening hours - Verified badge CTA: **View service** Secondary: **Book maintenance** --- # 15. Rider Dashboard Create a professional dashboard after login. ## Dashboard Overview Cards: ### Active Rental **Boxer 150** 120 EGP/day Status: **Active** ### Rental Remaining **18 days** ### Estimated Weekly Earnings **2,450 EGP** Label: **Estimated** ### Upcoming Maintenance **Oil change** Due in: **3 days** ### Job Matches **8 new opportunities** --- # 16. Dashboard Sections Sidebar: - Overview - My Motorcycle - Rental - Jobs - Earnings - Maintenance - Profile - Notifications - Support Mobile navigation should be optimized for riders. --- # 17. Rental Management Create a rental page showing: - Current motorcycle - Rental start date - Rental end date - Daily price - Deposit - Payment status - Rental status - Owner/fleet contact - Maintenance responsibility - Rental terms Include: **Extend rental** and **Report an issue** Do not implement real payments unless explicitly requested later. Use simulated payment states. --- # 18. Motorcycle Owner Dashboard Create a separate experience for motorcycle owners. Sections: - Overview - My motorcycles - Add motorcycle - Rental requests - Active rentals - Earnings - Maintenance - Messages - Profile Owner dashboard metrics: - Active motorcycles - Rented motorcycles - Available motorcycles - Monthly rental revenue - Pending requests --- # 19. Add Motorcycle Flow Form fields: - Brand - Model - Year - Engine capacity - Fuel type - Transmission - Location - Daily price - Weekly price - Monthly price - Deposit - Availability - Delivery box - Helmet - Maintenance included - Description - Photos Show a live preview of the motorcycle listing. --- # 20. Trust & Safety Trust is extremely important. Create UI concepts for: - Verified motorcycle - Verified owner - Maintenance status - Rental terms - Support - Issue reporting - Rider verification - Reviews Add clear warning/support states. Never imply that MotoRent guarantees income or eliminates all risk. --- # 21. Search UX Make search feel fast and modern. Add: - Instant filter updates - Sort by price - Sort by distance - Sort by relevance - Best for delivery - Highest rated - Available now Add a result summary: **24 motorcycles available for delivery work** --- # 22. Design System ## Overall Visual Direction The UI should be: - Modern - Professional - Bold - Urban - Mobile-first - High contrast - Trustworthy - Fast - Startup-quality - Suitable for Egyptian users Avoid: - Tourism aesthetics - Beach imagery - Luxury rental aesthetics - Excessive gradients - Excessive glassmorphism - Generic SaaS templates - Excessive rounded cards - Emoji-based UI --- # 23. Color Palette Use a motorcycle/work/energy inspired palette. ## Primary **Deep Charcoal / Graphite** `#111827` Use for: - Headers - Navigation - Primary dark surfaces - Strong typography ## Primary Accent **Safety Orange** `#F97316` Use for: - Main CTA - Active states - Price highlights - Important actions - Motorcycle/work indicators ## Secondary Accent **Electric Green** `#22C55E` Use selectively for: - Available - Verified - Successful - Earnings-positive states ## Supporting **Slate** `#64748B` For secondary text. ## Background **Off White** `#F8FAFC` For main application background. ## Dark Mode Support a polished dark mode using: - Graphite - Slate - Near-black surfaces - Orange accent - Green success Do not overuse orange. Orange should communicate **action and mobility**, not decorate every component. --- # 24. Typography Use a modern UI font. Prefer: - Inter - Manrope For Arabic support: - Cairo - IBM Plex Sans Arabic The product should support: **Arabic + English** Arabic must be properly RTL. Do not simply reverse English layouts. --- # 25. Icons Use a professional icon library such as: **Lucide** Do not use emojis as interface icons. Icons should be: - Consistent - Minimal - Accessible - Properly sized --- # 26. Components Build reusable components. Examples: - Navbar - SearchBar - FilterSidebar - FilterSheet - MotorcycleCard - MotorcycleGallery - PriceCard - RentalCalculator - EarningsCalculator - JobCard - MaintenanceCard - MatchScore - StatusBadge - VerificationBadge - DashboardSidebar - MobileBottomNav - EmptyState - LoadingState - ErrorState - ConfirmationModal - Toast - FormWizard Avoid duplicated markup. --- # 27. Responsive Design The product must be fully responsive. ## Desktop Use: - Spacious marketplace grid - Sidebar filters - Dashboard sidebar - Multi-column cards ## Tablet Adapt layouts without horizontal scrolling. ## Mobile This is extremely important because delivery riders will primarily use phones. Mobile requirements: - Sticky search/filter controls - Large touch targets - Easy CTA access - Bottom navigation - Compact cards - Fast scanning - One-handed interaction where possible - No horizontal overflow --- # 28. Navigation Public navigation: - Home - Motorcycles - Jobs - Maintenance - How it works - Become a partner - Login - Get started Authenticated rider navigation: - Dashboard - My Rental - Jobs - Earnings - Maintenance - Profile --- # 29. Main User Journey Implement the prototype around this journey: ```text Homepage ↓ Find a motorcycle ↓ Choose area ↓ Set budget ↓ Choose motorcycle/fuel ↓ Browse motorcycles ↓ Motorcycle details ↓ Rental calculator ↓ Request motorcycle ↓ Rider onboarding ↓ Rider dashboard ↓ Recommended delivery jobs ↓ Earnings tracking ↓ Maintenance reminders
